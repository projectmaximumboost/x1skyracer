# Maximum Engagement: the Game

This folder is home for the X1 Racing games and the game design for racing the SkyRacer.

- **Play today:** the regulation breakout game at [x1racing.com/game](https://x1racing.com/game).
- **Design ideas:** race courses over water, inflatable spires and landmarks, night races lined by small drones, reconfigurable tracks, "equalizer" spires, encircle spires, and turbulence zones. These live in the open problems section of the [main README](../README.md).

Nothing here is built yet. Game design notes, prototypes, art and rules for courses are welcome. Open an issue or send your idea.
